# PPT 制作规范

> 本规范是 `paper-group-meeting` Skill 的强制约束。步骤 4（大纲）与步骤 5（PPT 生成）必须遵循；
> 步骤 5C 渲染自检时按本规范逐项核对。
>
> **最高原则：PPT 是讲给人听的，把论文讲好是唯一目标。** 页数分配、语言选择、详略取舍都服从这一条。
>
> 规范的每一条都对应一次真实翻车：**通用套话、数据引用错误、页面无标题、逻辑断裂、
> 重点不突出、字号配色不统一、满屏英文术语、凑数页**。

---

## 一、内容筛选标准（相关性红线）

### 1.1 唯一信息源

**PPT 上的每一句话都必须能在论文原文里找到出处。**

- 允许的来源：摘要、Introduction、Related work、Methodology、Experiments、Conclusion、图表标题与表注。
- 禁止的来源：模型对「这类论文一般会讲什么」的先验知识。

**出处标注只写在大纲里，不上页面。** 大纲层面每条要点仍必须标注出处（`[§1 Intro]`、`[Table 3]`）供审核与自查；但**最终 PPT 页面上不得出现 `[§…]`、`[Fig. …]`、`[Table …]` 这类引用标记**——听众不需要看到「这句话出自 §3.2」，它只会挤占版面、干扰阅读。渲染前必须确认页面上没有任何出处标记残留。

### 1.2 高频违规形态（见到即删）

| 违规形态 | 典型表现 | 为什么违规 |
|---|---|---|
| **通用方法分类学** | 「Zero-shot 方法 / 重建类方法 / Few-shot 方法」三列对比，各配一句泛泛的原理描述 | 论文没有这组分类，也没这样论述。这是模型自己补的教科书背景 |
| **教科书定义** | 用一整页解释「什么是异常检测」这类背景概念 | 不是论文内容。注意与第二节 2.2 区分：**行内一句白话解释是强制要求**，整页科普才是违规 |
| **自造评价** | 「该方法具有很强的工程价值」「为工业质检提供了新思路」 | 论文没写，是模型的评价 |
| **自造局限** | 「依赖 CLIP 预训练表征」「超参数较多需调节」 | 论文的 Conclusion 只写了动态环境适应与多智能体协调成本 |
| **数字张冠李戴** | 把「相较此前方法的最大提升 1.28%」写成「较 PromptAD 提升 1.28%」 | 语义完全变了（PromptAD 实际只差 0.93%） |

### 1.3 数字必须可回溯

- 引用任何数值，必须能指到**具体表号或图号**（如 Table 3 / Table 6 / Table 7 / Fig. 1）。
- 论文正文与表格数字不一致时，**以表格为准**，并只用表格可直接算出的差值。
- 「最大提升」「SOTA」这类比较级表述，必须保留论文的比较对象限定语，不得替换成另一个方法名。

### 1.4 自检问题（写每一页时问自己）

1. 这条要点出自论文哪一节 / 哪张表？
2. 如果老师问「这个说法的依据是什么」，我能立刻翻到原文吗？
3. 这句话删掉，听众对论文的理解会变少吗？——不会就删。

## 二、语言与术语规范（讲给人听）

> PPT 是讲给人听的，不是论文的英文摘抄。听众要在几秒内看懂一页，满屏英文术语等于没讲。

### 2.1 中文优先

- **正文一律中文表述。** 除下方白名单外，任何英文术语都必须译成中文：
  - prompt → 提示文本；backbone → 骨干网络；fine-tuning → 微调；feature → 特征；pipeline → 流程
- **白名单**（允许保留英文，不必翻译）：
  - 论文提出的方法名（如 MALM-CLIP、MCEC、SCE）
  - 模型 / 骨干网络名（如 CLIP、ViT、GPT）
  - 数据集名（如 MVTec、VisA）
  - 通用指标缩写（如 AUROC、AP、PRO）
  - 图片内部原有的英文坐标轴 / 图例（图内文字不可改）
- 拿不准某个英文词是否属于白名单时，一律写中文。

### 2.2 重要术语首次出现必须给白话解释

- 论文的**关键概念 / 指标 / 机制**第一次在 PPT 出现时，附一句 **10–25 字的白话解释**，让没读过论文的听众也能跟上。
  - 正例：「AUROC（越接近 100% 检测越准）」「OCC（只用正常样本训练，没有异常样本）」
  - 反例：整页堆缩写，没有任何解释
- 白话解释直接取自步骤 3 术语表的「大白话解释」列，保持口径一致。
- 同一术语只解释一次，后续页面直接使用，不重复解释。
- 一页内首次出现的新术语不超过 **3 个**；超过说明这页内容该拆。

### 2.3 自检问题

1. 把这一页的英文全部遮住，意思还完整吗？——不完整就是英文用多了。
2. 一个没读过这篇论文的同学，只看 PPT 能跟上吗？

## 三、逻辑组织原则

### 3.1 必备叙事链条

整份 PPT 必须构成一条闭合的论证链，缺一环即需补：

```
问题（为什么需要这篇论文）
  → 已有工作的不足（缺口）
  → 本文方案（怎么做）
  → 实验验证（效果如何）
  → 结论与展望（说明了什么）
```

映射到页面就是四章：**论文介绍 → 方法 → 实验 → 结论**。

### 3.2 每页必须有清晰标题

- 标题必须**概括本页核心内容**，而不是只写章节号。
  - 反例：`2.3`
  - 正例：`2.3 MCEC 多智能体协作增强分类`
- 标题下方加一条**一句话结论横幅**（本页要让听众记住的那一句）。
  - 正例：`少样本训练只有正常样本、缺乏负样本 → SCE 用大模型自动生成异常文本，构造负样本做对比学习`
- 标题 + 横幅 = 听众扫一眼就知道这页在讲什么、结论是什么。

### 3.3 页间过渡

内容页**不加底部章节导航条**（「1 论文介绍 › 2 方法 › 3 实验 › 4 总结」）。实测中它既不被听众需要，又抢占内容区版面、与正文争空间。

- 页间过渡改由**每页一句话结论横幅 + 讲稿里的口播衔接句**承担：听众扫一眼横幅就知道这页结论，靠过渡句知道「讲到哪了」。
- 「讲到哪一章」的自查改在**大纲阶段**完成：大纲里给每页标注所属章节（作为幕后元数据），不渲染到页面。
- 目录页仍保留**逻辑主线**一行，把四章串成一句因果链：

```
人工 prompt 无法扩展 → 自动生成 prompt 与负样本 → 双数据集全面领先 → GenAI + CLIP 融合有效
```

### 3.4 页数分配：按论文内容重要性，不按固定占比

页数由**这篇论文本身的内容分布**决定，不由模板占比硬撑：

- **先盘点论文**：哪部分是本文的核心贡献（通常是方法 / 某个关键机制），就多给页；哪部分是常规操作（通常是实验设置、常规对比），就压缩。
- **方法是重点时**：方法章可以占到 40%–50%，一个核心模块一页不嫌多。
- **实验可以缩写**：实验设置 + 主结果 + 消融常规配置可压到 2–3 页；除非实验本身是论文最大亮点（如大规模对比、反直觉发现），不多给页。
- **每页必须有实质内容**：一页只讲一件事且这件事值得讲。写不出 3 条有出处的要点，说明这页不该存在——合并或删掉，**禁止凑数页**。
- **总页数服从「把论文讲清楚」**：standard 常规 12–18 页，但当论文内容确实需要时（公式多、模块多、实验充分）**放宽到 20 页出头也可以**，不为压页数而牺牲讲解完整性；quick / deep 区间同理可弹性上浮。

## 四、视觉呈现要求

### 4.1 设计令牌（从模板提取，禁止硬编码）

用户给了模板时，**先 dump 模板 XML 提取令牌**，再全部复用：

| 令牌 | 用途 | 本模板取值 |
|---|---|---|
| `FONT` | 全文字体 | 微软雅黑 |
| `TXT` | 正文色 | `#1F2937` |
| `CHIP_FILL` / `CHIP_LINE` | 标签块填充 / 描边 | `#4874CB` / `#2E54A1` |
| `EMPH` | 强调红 | `#C00000` |
| `SUB` | 图注 / 次级说明 | `#6B7280` |
| `DASH` | 分隔框描边 | `#B8C4D9` |

未给模板时（ppt-master 路径）：学术简约风，深蓝 + 灰白，16:9。

### 4.2 统一字号规范

| 层级 | 字号 | 说明 |
|---|---|---|
| 页面标题 | 32pt 加粗白字 | 模板标题条自带，不改 |
| 横幅（一句话结论） | 17pt 加粗 | 每页有且仅有一条 |
| 引导句 | 17pt | 重点页正文 |
| 标签块 | 15pt 加粗白字 | 同一页内标签块字号必须一致 |
| 正文 | 16pt | 默认正文 |
| 图注 | 11pt 灰 | 统一 `图 N　说明` 格式 |

**禁止**在同一页出现两个不同字号的正文，或同一页的标签块字号不一致。

### 4.3 重点突出

- **每页至少有一处强调**：本页最关键的数据或结论用 `EMPH` 红色加粗。
- 强调只给**结论和关键数值**，不给整段文字。
  - 正例：`MVTec-AD：94.38 / 95.55 / 96.40`（红）
  - 反例：整条 bullet 全红
- 一页内红色不超过 **3 处**，否则等于没有重点。

### 4.4 版面安全区

以 13.33 × 7.5 in 为例：

| 区域 | 坐标 | 约束 |
|---|---|---|
| 标题条 | `top ≈ 0`，高 0.94 | 模板自带，不覆盖 |
| 内容区 | `top 1.1 ~ 6.4` | 所有内容必须落在此区间 |
| 底部装饰条 | `top 6.56`，高 0.94 | 不得压字 |

字号估算：`每行字数 ≈ 宽度(in) × 72 ÷ 字号`。

**版面平衡：既不溢出，也不大片留白。** 溢出是硬伤；但内容页（封面 / 结束页除外）若出现超过约 1/3 页面的成片空白，同样不合格——说明这页讲得太少。补足方式：加一句「为什么这么设计」、给关键术语补白话解释、底部加一条一句话结论横幅，或直接与相邻页合并。

### 4.5 配图

- **只用 MinerU 图块**（`page:{N}/block:{B}`），禁止整页渲染图。
- 图片等比缩放并居中，不得拉伸变形。
- 每张图必须配图注，格式 `图 N　说明`；图注里引用数据集 / 指标时与正文一致。
- 判定整页图误用：长宽比接近 0.77（A4/Letter 竖版）即为可疑。**例外**：从 PDF 裁出的**公式原式截图**（小区域）允许入 PPT，它不是整页图。

### 4.6 公式呈现：优先裁论文原式截图，且必须讲透

核心公式**优先从论文 PDF 直接裁剪原式截图**上屏（PyMuPDF `clip` 区域导出 PNG），而不是手动重绘——重绘容易改符号、改上下标而出错，原式截图与论文 100% 一致，也省时。

裁剪要点：
- **先判版式再定裁剪框**：读该页正文块的 x 范围。**单栏排版要整宽裁**（正文块横跨全宽），双栏排版才按对应栏裁。按错版式会切掉公式的一半。
- 裁完必须目检：公式编号（如 `(5)`）与等号右端完整、无截断。
- 图注写「式 (N) 说明（论文原式截图）」。

**公式不能只放截图。** 每个公式页必须配**白话解释 + 设计意图**：
- 白话解释：把符号翻译成一句人话（例：式 (3) max 聚合 = 取节点与邻居特征差的最大分量，异常维度被直接挑出来）。
- 设计意图（why）：为什么这么设计、换成别的写法会怎样（例：用 max 而非 mean，因为 mean 会把异常维度平均稀释掉）。
- 白话口诀：给一串判断规则配一句顺口溜（例：明显异常信全局、模糊地带信局部、正常区域取平均）。

## 五、内容审核机制

步骤 5 生成 PPTX 后，**依次通过三关**，任一关不通过即返工。

### 第一关：内容与语言审核（对着论文 + 白名单查）

逐页回答，全部为「是」才算通过：

- [ ] 本页每一条要点都能指到论文的具体章节 / 表号 / 图号
- [ ] 没有出现「通用方法分类学」「教科书定义」「自造评价」「自造局限」
- [ ] 所有数值与论文表格一致，且比较对象没有被替换
- [ ] 没有出现旧论文残留（旧标题、旧模块名、旧公式、旧表格）
- [ ] 正文中文优先：白名单（方法名 / 模型名 / 数据集名 / 指标缩写）之外无英文术语
- [ ] 重要术语首次出现处有白话解释，且一页新术语不超过 3 个
- [ ] 无凑数页：每页至少 3 条有出处的实质要点，页数按论文重要性分配

> 执行方式：把大纲逐条与论文结构化全文对照。**不确定的条目直接删掉**，不要保留「大概是这个意思」的内容。

### 第二关：逻辑连贯性审核

- [ ] 每页标题都能概括本页核心内容（不是只有章节号）
- [ ] 每页都有且仅有一句话结论横幅
- [ ] 四章齐全且顺序为「介绍 → 方法 → 实验 → 结论」
- [ ] 页面**无底部章节导航条**、**无 `[§…]` / `[Fig.]` / `[Table]` 出处标记**
- [ ] 目录页有逻辑主线，能把四章串成因果链
- [ ] 抽掉任意一页，叙事会出现断点（说明每页都有存在必要）

### 第三关：视觉与重点审核（渲染成图后查）

用 PowerPoint COM 渲染成 PNG，逐页看：

- [ ] 文字无溢出（未超出文本框 / 标签块 / 底板）
- [ ] 文字无重叠（封面标题与汇报人信息是高频出错点）
- [ ] 每页至少一处红色强调，且不超过 3 处
- [ ] 字号、配色与第四节规范一致
- [ ] 图片全部为图块，无整页截图（公式原式截图除外）
- [ ] 内容页无成片空白（超过约 1/3 页面即为不合格）
- [ ] 公式页：原式截图完整（编号与右端未截断），且配有白话解释与设计意图
- [ ] 无底部导航条残留、无出处标记残留
- [ ] 元素未压到底部装饰条
- [ ] 空页 / 缺图检查

### 返工规则

- 第一关不通过 → 回步骤 4 改大纲，再重新生成 PPT
- 第二关不通过 → 改标题 / 补横幅 / 调页序，重新生成 PPT
- 第三关不通过 → 改坐标或字号，**重新渲染复检**

## 六、常见翻车与对策速查

| 症状 | 根因 | 对策 |
|---|---|---|
| 「内容与论文无关」 | 用先验知识补背景 | 第一节：每条要点标注论文出处 |
| 「数据不对」 | 比较对象被替换 | 第一节 1.3：以表格为准，保留限定语 |
| 「排版乱」 | 沿用旧模板残留 | 步骤 5A：整页清空重绘，不靠替换文字 |
| 「图片没用 / 是整页图」 | 用了 page 级渲染 | 步骤 1：图块与整页预览分开导出 |
| 「逻辑跳跃」 | 无标题、无过渡 | 第三节：标题 + 横幅 + 讲稿过渡句 |
| 「页面有 `[§3.2]` 引用」 | 把大纲的幕后出处带进了页面 | 第一节 1.1：出处只写大纲，渲染前清除 |
| 「内容页大片留白」 | 讲得太少 / 该页该合并 | 第四节 4.4：补 why / 白话解释 / 结论横幅 |
| 「公式看不懂」 | 只贴截图没解释 | 第四节 4.6：白话解释 + 设计意图 |
| 「公式裁一半」 | 误按双栏裁单栏 PDF | 第四节 4.6：先判版式再裁，单栏整宽 |
| 「看不出重点」 | 关键数据混在正文 | 第四节 4.3：每页 1–3 处红色加粗 |
| 「风格不统一」 | 硬编码字号颜色 | 第四节 4.1/4.2：统一令牌与字号表 |
| 「满屏英文看不懂」 | 把 PPT 当论文英文摘抄 | 第二节：中文优先 + 白名单 + 术语白话解释 |
| 「凑数页 / 详略不当」 | 按固定占比硬撑页数 | 第三节 3.4：按论文内容重要性分配，每页必须有实质内容 |
| 消耗算力翻倍 | 多路 agent 生成同一份 PPT | 步骤 5 职责边界：主流程单独负责 |
