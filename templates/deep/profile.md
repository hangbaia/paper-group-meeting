# deep 模板（深度研讨，约 30 分钟）

基于 `standard` 模板执行，并按以下差异覆盖：

| 项目 | 覆盖设定 |
|---|---|
| PPT 页数 | 20–28 页 |
| 讲稿口语量 | 每页约 250–350 字，全稿约 6000–8000 字 |
| 论文解读 | 一级、二级、**三级子节全部展开**；每节额外补充「推导过程」与「与相邻工作的差异」 |
| 公式 | 详解 5–8 个公式，含完整推导步骤与维度流验证 |
| 实验 | 全部消融逐项展开，附复现要点（超参、硬件、训练时长） |
| 术语表 | 15–20 条，含数学背景术语 |
| Q&A 预案 | 8 题（3 基础 + 5 深入），深入题附「若被追问」二层预案 |
| 额外产出 | 在解读文档末尾追加「复现清单」：数据、代码、超参、算力需求、已知坑 |

## 推荐额外页面

- 方法推导页（每个核心公式一页，逐步骤展开）
- 消融实验专项页（每张消融表一页）
- 复现要点页（环境、超参、训练时长、常见失败模式）
- 与 2–3 篇核心工作的逐点对比页

## 适用场景

论文研讨课、开题/中期答辩的方法学汇报、需要复现该工作的组内分享。

## 注意

深度展开不等于堆砌：每个补充推导必须标注「【隐含逻辑】」，区分原文结论与自己的推导。
